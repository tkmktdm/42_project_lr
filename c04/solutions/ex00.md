# ex00 — ft_strlen

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_strlen.c` |
| プロトタイプ | `int  ft_strlen(char *str);` |
| 使える関数 | None（ライブラリ関数禁止） |
| 禁止 | グローバル変数 |
| やること | 文字列の長さ（`\0` を含まない文字数）を返す |

---

## 考え方

- 文字列はメモリ上に連続して並び、末尾に `\0`（ヌル文字）がある
- `\0` に当たるまでインデックスを進め、カウントを返すだけ
- ループは `while (str[i])` で `\0` を自動判定できる（`\0` は偽なのでループ終了）

### 用語メモ

- **ヌル終端文字列**: C の文字列はバイト列の末尾に `\0`（値 0）を持つ規約。`strlen` はこれを使って長さを計算する
- **`int` vs `size_t`**: 標準 `strlen` は `size_t`（符号なし）を返すが、この課題は `int` を返す。負の長さはあり得ないが型に注意

---

## メモリ図解

```
str = "Hello"

インデックス:  0    1    2    3    4    5
              'H'  'e'  'l'  'l'  'o'  '\0'
               ^                        ^
               str                      ここで while ループが止まる

len のカウント: 0 → 1 → 2 → 3 → 4 → 5
return 5;
```

---

## 解答コード

```c
#include <unistd.h>  /* 不要だが提出コードに含まれる場合もある */

int     ft_strlen(char *str)
{
    int len;

    len = 0;
    while (str[len])
        len++;
    return (len);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `int len = 0;` | カウンタの初期値は必ず 0 にする |
| `while (str[len])` | `str[len]` が `\0`（= 0 = false）になったら終了 |
| `len++` | `\0` 以外の文字が見つかるたびにカウントアップ |
| `return (len)` | `\0` は含めないので、ループ終了時点の len がそのまま長さ |

---

## ハマりポイント

### ❌ NG: `\0` 自体をカウントしてしまう

```c
while (str[len] != '\0')
    len++;
return (len + 1);  /* +1 は間違い */
```

→ `\0` はヌル終端であり長さに含めない。`strlen("Hello") == 5`（`\0` を除く）

---

### ❌ NG: 標準ライブラリを使う

```c
#include <string.h>
return ((int)strlen(str));  /* 禁止 */
```

→ 使用可能な関数が None なので外部シンボルが `nm -u` に現れると不正
