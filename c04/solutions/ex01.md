# ex01 — ft_putstr

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_putstr.c` |
| プロトタイプ | `void  ft_putstr(char *str);` |
| 使える関数 | `write` のみ |
| 禁止 | グローバル変数 |
| やること | 文字列を標準出力に 1 文字ずつ出力する |

---

## 考え方

- `write` は 1 回の呼び出しでまとめて書き込める（`write(1, str, len)` で全部出せる）
- ただし長さを事前に知る必要がある → `ft_strlen` 的なカウントが要る
- 1 文字ずつ出す方が実装が単純（`while` + `write(1, &str[i], 1)`）
- `\n` は関数が出力しない（呼び出し側が必要なら追加する）

### 用語メモ

- **`write(fd, buf, n)`**: カーネルに直接バイト列を渡すシステムコール。`fd=1` は stdout
- **`&str[i]`**: `str[i]` の値ではなく**アドレス**を渡す必要がある（`write` は `const void *` を受け取る）

---

## メモリ図解

```
str = "Hi"

  i=0  i=1  i=2
  'H'  'i'  '\0'
   ^
   &str[0]  → write(1, &str[0], 1)  → stdout に 'H'
        ^
        &str[1]  → write(1, &str[1], 1)  → stdout に 'i'
              ^
              str[2] == '\0' → while ループ終了

出力: Hi
```

---

## 解答コード

```c
#include <unistd.h>

void    ft_putstr(char *str)
{
    int i;

    i = 0;
    while (str[i] != '\0')
    {
        write(1, &str[i], 1);
        i++;
    }
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `#include <unistd.h>` | `write` の宣言がここにある |
| `while (str[i] != '\0')` | `\0` で終わり。`while (str[i])` でも同じ |
| `write(1, &str[i], 1)` | 1 byte = 1 文字を stdout へ。`str[i]` ではなく `&str[i]` |

---

## ハマりポイント

### ❌ NG: printf を使う

```c
printf("%s", str);  /* write 以外の出力関数は禁止 */
```

→ `nm -u` に `printf` が現れると不正判定

---

### ❌ NG: `write(1, str[i], 1)` → アドレスではなく値を渡す

```c
write(1, str[i], 1);  /* コンパイルエラー: int を void* に渡せない */
```

→ `write` の第 2 引数は「書き込むデータの先頭アドレス」。`&str[i]` でアドレスを渡す
