# ex04 — ft_putnbr_base

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_putnbr_base.c` |
| プロトタイプ | `void  ft_putnbr_base(int nbr, char *base);` |
| 使える関数 | `write` のみ |
| 禁止 | グローバル変数 |
| やること | 整数を指定ベースの文字列として stdout に出力する |

**無効なベースの条件（何も出力しない）**
- ベースが空 or 長さ 1 以下
- ベースに `+` または `-` が含まれる
- ベースに重複文字が含まれる

**PDF の例**
- `"0123456789"` → 10 進数
- `"01"` → 2 進数
- `"0123456789ABCDEF"` → 16 進数
- `"poneyvif"` → 8 進数

---

## 考え方

- ベースの長さ `n` が「基数」になる（10進数なら10、2進数なら2）
- 数値を `n` で割り続けて余りを集めると下の桁から順に出る → **再帰**で逆順出力
- 負数は `-` を出力してから絶対値で処理（`long` にキャストして INT_MIN の `-(-n)` オーバーフローを回避）
- ベース検証は出力前に必ず行う

### 用語メモ

- **基数変換**: 整数 N を基数 B で表す。`N % B` が末尾の桁、`N / B` で桁を削る
- **再帰の向き**: `ft_putnbr(n/B)` → `ft_putnbr(n%B)` の順に呼ぶことで高い桁から出力

---

## メモリ図解

```
ft_putnbr_base(255, "0123456789ABCDEF")
  基数 n = 16

  再帰ツリー:
  ft_putnbr(255, 16)
    255 > 15 なので先に ft_putnbr(255/16=15, 16)
      15 > 15 は偽 → base[15] = 'F' を write → 出力: 'F'
    戻ってきて base[255%16=15] = 'F' を write → 出力: 'F'

  結果: "FF"  ✓

ft_putnbr_base(-42, "0123456789")
  n < 0 → write('-') → n = 42
  ft_putnbr(42, 10)
    42 > 9 → ft_putnbr(4, 10)
      4 <= 9 → base[4] = '4' を write
    base[42%10=2] = '2' を write
  結果: "-42"  ✓
```

## 解答コード

```c
#include <unistd.h>

int     base_check(char *base)
{
    int i;
    int j;

    i = 0;
    while (base[i])
    {
        if (base[i] == '+' || base[i] == '-')
            return (0);
        i++;
    }
    if (i <= 1)
        return (0);
    i = 0;
    while (base[i])
    {
        j = i + 1;
        while (base[j])
        {
            if (base[i] == base[j])
                return (0);
            j++;
        }
        i++;
    }
    return (i);
}

static void     write_base(long n, int nx, char *base)
{
    if (n > nx - 1)
        write_base(n / nx, nx, base);
    n = base[n % nx];
    write(1, &n, 1);
}

void    ft_putnbr_base(int nbr, char *base)
{
    int  n;
    long nb;

    n = base_check(base);
    if (!n)
        return ;
    nb = nbr;
    if (nb < 0)
    {
        write(1, "-", 1);
        nb = -nb;
    }
    write_base(nb, n, base);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `base_check` で `return (i)` | 検証 OK の場合にベース長（基数）をそのまま返す。0 は無効の意味も兼ねる |
| `long nb = nbr` | INT_MIN = -2147483648 を `-nb` するとオーバーフロー。`long` に逃がす |
| `write_base` で再帰 | 高い桁 `n/nx` を先に出力してから末尾桁 `n%nx` を出力 |
| `n = base[n % nx]` | インデックスをベース文字に変換してから `write` |

## ハマりポイント

### ❌ NG: int のまま -INT_MIN を取ると undefined behavior

```c
int n = nb;
if (n < 0)
    n = -n;  /* INT_MIN = -2147483648 → -(-2147483648) がオーバーフロー */
```

→ `long` にキャストしてから `n = -n` にすること

---

### ❌ NG: ベース長さ 1 をチェックしない

```c
while (base[i])
    i++;
/* i == 1 のケースをチェックし忘れる */
```

→ 長さ 1 も無効。`if (i <= 1) return (0)` が必要

---

### ❌ NG: ベースに `+`/`-` だけチェックしてスペースを忘れる（ex05 と混同注意）

- ex04（ft_putnbr_base）では**スペースは無効条件に含まれない**
- ex05（ft_atoi_base）ではスペースも無効条件に含まれる
