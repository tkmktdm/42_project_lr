# ex01 — ft_print_params

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_print_params.c` |
| プロトタイプ | `int main(int ac, char **av)` |
| 使える関数 | `write` のみ |
| 禁止 | グローバル変数、`printf` など |
| やること | `argv[0]` 以外の引数を、コマンドラインと同じ順番で1行に1つずつ出力 |

---

## 考え方

- `i = 1` から始めて `i < ac` の間ループ（`argv[0]` はプログラム名なので飛ばす）
- 各引数 `av[i]` を1文字ずつ出力し、終わったら `\n` を出力
- 引数が0個（`ac == 1`）なら何も出力しない

### 用語メモ

- **argc**: 引数の総数。`./prog a b` の場合 `argc == 3`（`argv[0]` を含む）
- **argv[1..ac-1]**: 実際に渡された引数群

---

## メモリ図解

```
./a.out test1 test2 test3 で実行した場合

  argc = 4

  argv
  ┌─────────┐
  │ av[0] ──┼──→  "./a.out\0"   ← 出力しない
  ├─────────┤
  │ av[1] ──┼──→  "test1\0"     ← 出力: test1\n
  ├─────────┤
  │ av[2] ──┼──→  "test2\0"     ← 出力: test2\n
  ├─────────┤
  │ av[3] ──┼──→  "test3\0"     ← 出力: test3\n
  ├─────────┤
  │ av[4] ──┼──→  NULL
  └─────────┘

  外ループ: i = 1, 2, 3
  内ループ: *av[i] != '\0' の間、1文字ずつ出力
```

---

## 解答コード

```c
#include <unistd.h>

void    ft_putchar(char c)
{
    write(1, &c, 1);
}

int     main(int ac, char **av)
{
    int i;

    i = 1;
    while (i < ac)
    {
        while (*av[i] != '\0')
        {
            ft_putchar(*av[i]);
            av[i]++;
        }
        ft_putchar('\n');
        i++;
    }
    return (0);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `i = 1` | `av[0]` はプログラム名なので 1 から開始 |
| `while (i < ac)` | `av[ac]` は NULL なので `ac` 未満まで |
| `while (*av[i] != '\0')` | 各引数の文字列を末尾まで走査 |
| `av[i]++` | `av[i]` のポインタを1文字進める |
| `ft_putchar('\n')` | 1引数出力完了ごとに改行 |

---

## ハマりポイント

### ❌ NG: i = 0 から始める

```c
i = 0;  // argv[0]（プログラム名）まで出力してしまう
while (i < ac)
    ...
```

→ PDF の仕様「`argv[0]` 以外のすべての引数を出力」に反する

---

### ❌ NG: i <= ac

```c
while (i <= ac)  // av[ac] は NULL → デリファレンスでクラッシュ
```

→ `av[ac]` は `NULL` ポインタ。`*av[ac]` にアクセスするとセグメンテーション違反

---

### 引数なしの挙動

```
./a.out  （引数なし）
   argc = 1
   i = 1, 条件 1 < 1 は false → ループに入らない → 何も出力されない ✓
```
