# ex00 — ft_print_program_name

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_print_program_name.c` |
| プロトタイプ | `int main(int ac, char **av)` |
| 使える関数 | `write` のみ |
| 禁止 | グローバル変数、`printf` など |
| やること | `argv[0]`（実行されたプログラム名）を標準出力に出力し、改行を付ける |

---

## 考え方

- `argv[0]` は「実行されたコマンドそのもの」が入る文字列へのポインタ
- `argv[0]` を1文字ずつ `write` で出力し、最後に `\n` を出力するだけ
- `ac` を 0 にリセットしてインデックスとして再利用するのは一般的なテクニック（ただし可読性のために別変数 `i = 0` を使うほうが明示的）

### 用語メモ

- **argv[0]**: 実行コマンドそのもの。`./a.out` なら `"./a.out"` が入る
- **argc**: 引数の数（`argv[0]` を含む）。引数なしで実行しても `argc == 1`

---

## メモリ図解

```
./ex00_bin で実行した場合

  argv（char** 配列）
  ┌─────────┐
  │ av[0] ──┼──→  "./ex00_bin\0"   ← プログラム名
  ├─────────┤
  │ av[1] ──┼──→  NULL             ← 引数なしなのでここで終端
  └─────────┘

  ループ: *av[0] != '\0' の間、1文字ずつ write(1, &c, 1) で出力
  '.'  '/'  'e'  'x'  '0'  '0'  '_'  'b'  'i'  'n'  '\n'
```

## 解答コード

```c
#include <unistd.h>

void    ft_putchar(char c)
{
    write(1, &c, 1);
}

int     main(int ac, char **av)
{
    ac = 0;
    while (*av[ac] != '\0')
    {
        ft_putchar(*av[ac]);
        av[ac]++;
    }
    ft_putchar('\n');
    return (0);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `ac = 0` | `ac` を `av` のインデックスとして再利用。`av[0]` を参照するため 0 を代入 |
| `*av[ac] != '\0'` | `av[0]` が指す文字列の末尾（`\0`）まで繰り返す |
| `ft_putchar(*av[ac])` | `av[ac]` はポインタなので `*` でデリファレンスして1文字取得 |
| `av[ac]++` | `av[0]` のポインタを1文字分進める（文字列を走査） |
| `ft_putchar('\n')` | PDF 仕様通り、末尾に改行を出力 |

---

## ハマりポイント

### ❌ NG: `printf` を使う

```c
printf("%s\n", av[0]);  // printf は使用不可
```

→ 使える関数は `write` のみ。`nm -u` で `printf` が検出されると失敗

---

### ❌ NG: 改行を忘れる

```c
while (*av[0] != '\0')
    ft_putchar(*av[0]++);
// ft_putchar('\n'); を書かない
```

→ PDF の出力例 `./a.out$` の `$` は改行の存在を示している。必須

---

### 注意: `av[ac]++` はポインタを進めている

```
av[0] = 0x7fff1000  → "hello\0"

1回目: *av[0] = 'h', write → av[0] = 0x7fff1001
2回目: *av[0] = 'e', write → av[0] = 0x7fff1002
...
終了:  *av[0] = '\0', ループ終了
```

`av[0]` 自体（ポインタ変数）が書き換わっているが、元の文字列データは変わらない
