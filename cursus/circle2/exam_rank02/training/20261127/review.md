## 2. ft_strpbrk（Level 2）— ❌ ギブアップ

### つまずいたところ
- strpbrk が何をする関数か分からなかった（Examples がない問題）
- main でいろいろ試していたが、関数の形にできなかった

### strpbrk の動き
s1 を先頭から1文字ずつ見て、**s2 のどれかの文字と同じ文字**が出たら、その場所（ポインタ）を返す。最後まで見つからなければ `NULL` を返す。

```
s1 = "hey!"   s2 = "abcd"   → h,e,y,! のどれも a,b,c,d にない → NULL
s1 = "hello"  s2 = "xl"     → h(×) e(×) l(○) → "llo" の先頭を返す
```

### 解答

```c
#include <stddef.h>

char	*ft_strpbrk(const char *s1, const char *s2)
{
	int	i;
	int	j;

	i = 0;
	while (s1[i])
	{
		j = 0;
		while (s2[j])
		{
			if (s1[i] == s2[j])
				return ((char *)&s1[i]);
			j++;
		}
		i++;
	}
	return (NULL);
}
```

| 行 | 意味 |
|----|------|
| `#include <stddef.h>` | `NULL` を使うため |
| `while (s1[i])` | s1 を1文字ずつ進める（外側のループ） |
| `j = 0;` | s1 の文字が変わるたびに、s2 を最初から見直す |
| `while (s2[j])` | 今の s1 の文字を、s2 の全部の文字と比べる（内側のループ） |
| `return ((char *)&s1[i]);` | 見つかったらその**場所**（`&`）を返す。const を外すためにキャストする |
| `return (NULL);` | 最後まで見つからなかった |

### 配列の書き方とポインタの書き方
どちらも同じ意味。**試験では配列の書き方（`[i]`）に統一する**。

| 配列 | ポインタ | 意味 |
|------|----------|------|
| `s1[i]` | `*s1` | 今の文字 |
| `i++` | `s1++` | 次へ進む |
| `&s1[i]` | `s1` | 今の文字の場所 |

### 書き直し1回目: ❌ FAIL

1. **コンパイルエラー**: `return &s1[i];` → `return ((char *)&s1[i]);`（const を外すキャストが必要）
2. **`j = 0;` がループの外** → s1 の1文字目で j が s2 の最後まで進み、2文字目以降は内側の while に入らない。
   見つかる文字が s1 の1文字目でない限り NULL になる（`("hello","orz")` → 本物は `o`、自分は `NULL`）。
   `j = 0;` は外側の while の中、内側の while の**直前**に置く
3. 提出時は main と `#include` を消す

良かった点: 配列の書き方で統一できた。`return 0;` は NULL と同じ意味なので OK（include も不要になる）。

### 書き直し2回目: ❌ FAIL（コンパイルエラーのみ）

- `j = 0;` を内側の while の**後ろ**に置いて解決。直前に置くのと同じ効果で、正しい
- キャストを補えば全7ケースで本物と一致。ロジックは完成
- **残り: `return &s1[i];` のキャストがまだない** → コンパイルできないので本番は0点

### 書き直し3回目: 関数は ✅ 完成（main が残っているので提出としては FAIL）

- キャスト `((char*)&s1[i])` を付けてコンパイルが通った。全7ケースで本物と一致
- 採点用の main とつなぐと `duplicate symbol '_main'` → **提出時は main と #include を必ず消す**
- `return 0;` は `return NULL;` と同じ意味で OK（0 はポインタとして使うと NULL になる）

### 同じ形の問題
「s1 の各文字について、s2 の中にあるか調べる」二重ループは **ft_strcspn・ft_strspn** と同じ形。
3つまとめて覚えると効率がよい（戻り値が違うだけ）。

| 関数 | 返すもの |
|------|----------|
| ft_strpbrk | s2 の文字が**最初に出た場所**（ポインタ） |
| ft_strcspn | s2 の文字が**最初に出るまでの長さ** |
| ft_strspn | s2 の文字**だけが続く長さ** |

### 最終: ✅ PASS
main をコメントアウトして提出。採点用 main とつないでも通り、全7ケースで本物と一致。
