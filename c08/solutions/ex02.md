## 考え方

- `ABS(x)` は `x >= 0` なら `x` を、`x < 0` なら `-x` を返す
- 関数ではなく **マクロ** なので、`int` だけでなく `float` や `long` にも使える
- マクロの引数は必ず括弧で囲む

### 用語メモ

- **三項演算子**: `条件 ? 真の値 : 偽の値` の形の式。`if-else` をワンライナーで書ける
- **マクロ副作用**: `ABS(i++)` のように引数に副作用があると二重評価されてバグになる。マクロの限界

---

## 絶対値の仕組み

```
ABS(5)  → 5 >= 0  → 5
ABS(-5) → -5 < 0  → -(-5) = 5
ABS(0)  → 0 >= 0  → 0

三項演算子:
  (Value) < 0  ?  -(Value)  :  (Value)
     ↑               ↑            ↑
  判定          負のとき符号反転  正のときそのまま
```

---

## 算術トリックによる実装（htakumi の実装）

```c
# define ABS(Value) ((Value) * (1 - 2 * ((Value) < 0)))
```

`if` も三項演算子も使わず、**算術だけで絶対値を求める**方法。

### `1 - 2 * ((Value) < 0)` の意味

`(Value) < 0` は C言語の比較演算子で **真=1、偽=0** しか返せない。
これをそのまま使っても +1/-1 の係数にはできないため `1 - 2 × フラグ` で変換する。

| フラグ | 欲しい係数 | 計算 |
|--------|-----------|------|
| 0（正） | **+1** | `1 - 2×0 = +1` |
| 1（負） | **-1** | `1 - 2×1 = -1` |

```
フラグ:  0 -------- 1
          ×2
         0 -------- 2
          1 -
         +1 -------- -1  ← 欲しかった係数
```

`1` を基点に `2` 引くことで、**0→+1、1→-1** のマッピングが一発でできる。

### 全パターン確認

| Value | `(V) < 0` | `2 * ...` | `1 - ...` | 計算 | 結果 |
|-------|-----------|-----------|-----------|------|------|
| 5 | 0 | 0 | **+1** | 5 × 1 | **5** |
| -3 | 1 | 2 | **-1** | -3 × -1 | **3** |
| 0 | 0 | 0 | **+1** | 0 × 1 | **0** |

## 解答コード

```c
#ifndef FT_ABS_H
# define FT_ABS_H

# define ABS(Value) (((Value) < 0) ? (-(Value)) : (Value))

#endif
```

**なぜそう書くか**

| コード | 理由 |
|--------|------|
| `(Value)` を括弧で囲む | `ABS(a - b)` など式を渡したとき正しく展開される |
| `(-(Value))` を括弧で囲む | 展開結果が他の演算子に食われないため |
| 全体を括弧で囲む | `ABS(x) * 2` が `(ABS(x)) * 2` として正しく計算される |
| `-R CheckDefine` 準拠の `# define` | `#` の後にスペース |

---

## ハマりポイント

### ❌ NG: 括弧なし

```c
# define ABS(Value) Value < 0 ? -Value : Value
```

→ `ABS(3 - 5) * 2` が `3 - 5 < 0 ? -3 - 5 : 3 - 5 * 2` のように誤展開される

---

### ❌ NG: 副作用のある引数

```c
int i = -3;
int r = ABS(i++);
// 展開後: ((i++) < 0) ? (-(i++)) : (i++)
// i++ が2回評価される！
```

→ 使う側の問題だが、マクロの制限として知っておく

---

### ❌ NG: 関数にする

```c
int abs(int n) { return (n < 0 ? -n : n); }  // 関数
```

→ 課題はマクロを求めているので `-R CheckDefine` でチェックされる。関数では不正解
