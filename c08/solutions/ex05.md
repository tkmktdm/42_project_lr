# ex05 — ft_show_tab

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_show_tab.c` + `ft_stock_str.h` |
| 提出先 | `ex05/` |
| プロトタイプ | `void ft_show_tab(struct s_stock_str *par);` |
| 使える関数 | `write` |
| やること | `ft_strs_to_tab` が作った配列を標準出力に表示 |

### 出力フォーマット（各要素につき）

```
[str の内容]
[size の数値]
[copy の内容]
```

例: `["hello", "world"]` を渡したとき:
```
hello
5
hello
world
5
world
```

---

## 考え方

- `par->str != NULL` の間ループ（終端マーカーで止まる）
- 各要素で: `str`, 改行, `size`（数値）, 改行, `copy`, 改行 を出力
- `write` しか使えないので数値出力用の `ft_putnbr` を自作する
- ポインタインクリメント `par++` で次の要素に進む

### 用語メモ

- **`par++`**: 構造体ポインタのインクリメント。`sizeof(struct s_stock_str)` 分だけアドレスが進む
- **`ft_putnbr`**: `write` のみで整数を出力する再帰実装。桁を一つずつ出力

---

## メモリ図解

```
par が指す配列を順番に出力:

par ──► tab[0] ──► str = "hello", size = 5, copy = "hello"
         出力: "hello\n5\nhello\n"
         par++
par ──► tab[1] ──► str = "world", size = 5, copy = "world"
         出力: "world\n5\nworld\n"
         par++
par ──► tab[2] ──► str = 0 (NULL)
         ループ終了
```

---

## 解答コード

```c
#include "ft_stock_str.h"
#include <unistd.h>

static void ft_putstr(char *str)
{
    while (*str)
    {
        write(1, str, 1);
        str++;
    }
}

static void ft_putnbr(int nb)
{
    long    n;
    char    c;

    n = nb;
    if (n < 0)
    {
        write(1, "-", 1);
        n = -n;
    }
    if (n >= 10)
        ft_putnbr(n / 10);
    c = (n % 10) + '0';
    write(1, &c, 1);
}

void    ft_show_tab(struct s_stock_str *par)
{
    while (par->str != NULL)
    {
        ft_putstr(par->str);
        write(1, "\n", 1);
        ft_putnbr(par->size);
        write(1, "\n", 1);
        ft_putstr(par->copy);
        write(1, "\n", 1);
        par++;
    }
}
```

**なぜそう書くか**

| コード | 理由 |
|--------|------|
| `while (par->str != NULL)` | 終端マーカー（`str=0`）でループを止める |
| `par++` | ポインタを次の構造体要素へ進める |
| `long n = nb` | `INT_MIN` を `-n` すると int でオーバーフローするので long に変換 |
| `c = (n % 10) + '0'` | 数字を ASCII 文字に変換（`'0'` = 48） |
| 補助関数を `static` に | `ft_putstr`, `ft_putnbr` は外部から呼ばれない |

---

## ft_putnbr の動き（例: 42）

```
ft_putnbr(42)
  ├── n=42 >= 10 → ft_putnbr(4)
  │     ├── n=4 < 10 → c = '4', write '4'
  └── c = '2', write '2'

出力: "42"
```

## ハマりポイント

### ❌ NG: INT_MIN のオーバーフロー

```c
if (nb < 0)
    nb = -nb;  // INT_MIN (-2147483648) を -nbすると int でオーバーフロー
```

→ `long n = nb;` に変換してから `-n` を使う

---

### ❌ NG: par を配列インデックスで使う

```c
int i = 0;
while (par[i].str != NULL)
{
    // par[i] でアクセス
    i++;
}
```

→ 動作は同じだが、`par++` の方がポインタを直接進める慣用的な書き方

---

### ❌ NG: ft_putstr に write を複数回呼ぶ

```c
write(1, par->str, ft_strlen(par->str));  // これでもOK
```

→ 使ってよい（`ft_strlen` は自作すれば使える）。ただし `write` のみ許可されているので注意

---

### ❌ NG: copy が修正されている可能性を忘れる

PDF には「copy（修正されている可能性があるもの）」と書かれている。  
`copy` は独立したコピーなので `str` と異なる内容になりうる。`copy` をそのまま表示すればよい。
