# ex04 — ft_is_sort

## 要件

| 項目 | 内容 |
|------|------|
| ファイル | `ft_is_sort.c` |
| プロトタイプ | `int ft_is_sort(int *tab, int length, int (*f)(int, int))` |
| 使える関数 | None |
| やること | 配列がソートされていれば1、そうでなければ0を返す |

---

## 考え方

`f(a, b)` の仕様：
- `a < b` → 負の値
- `a == b` → 0
- `a > b` → 正の値

「ソート済み」= **昇順 OR 降順** どちらでもOK。

- `asc`（昇順フラグ）と `desc`（降順フラグ）を用意
- `f(tab[i], tab[i+1]) > 0` → 前 > 後 なので昇順が崩れる → `asc = 0`
- `f(tab[i], tab[i+1]) < 0` → 前 < 後 なので降順が崩れる → `desc = 0`
- 最後に `asc || desc` を返す

---

## 解答コード

```c
int     ft_is_sort(int *tab, int length, int (*f)(int, int))
{
    int i;
    int asc;
    int desc;

    asc = 1;
    desc = 1;
    i = 0;
    while (i < length - 1)
    {
        if (f(tab[i], tab[i + 1]) > 0)
            asc = 0;
        if (f(tab[i], tab[i + 1]) < 0)
            desc = 0;
        i++;
    }
    return (asc || desc);
}
```

---

## ハマりポイント

### 昇順だけチェックはNG
```c
// ❌ 降順配列 [4,3,2,1] を 0 と判定してしまう
if (f(tab[i], tab[i+1]) > 0) return (0);
```

### 全要素が同じ配列 [2,2,2]
`asc` も `desc` も崩れないので `1 || 1 = 1` → 正しくソート済みと判定される。

### length <= 1
ループが回らず `asc=1, desc=1` のまま → `return (1)` → 正しい。
