# ex01 — ft_map

## 要件

| 項目 | 内容 |
|------|------|
| ファイル | `ft_map.c` |
| プロトタイプ | `int *ft_map(int *tab, int length, int (*f)(int))` |
| 使える関数 | `malloc` |
| やること | 各要素に `f` を適用した結果を格納した**新しい配列**を返す |

---

## 考え方

1. `malloc(sizeof(int) * length)` で新しい配列を確保
2. `result[i] = f(tab[i])` で埋める
3. ポインタを返す（呼び出し元が `free` する責任を持つ）

---

## 解答コード

```c
#include <stdlib.h>

int     *ft_map(int *tab, int length, int (*f)(int))
{
    int *result;
    int i;

    result = malloc(sizeof(int) * length);
    if (!result)
        return (NULL);
    i = 0;
    while (i < length)
    {
        result[i] = f(tab[i]);
        i++;
    }
    return (result);
}
```

---

## ハマりポイント

### malloc の失敗チェック
`malloc` が `NULL` を返す可能性がある。必ず `if (!result) return (NULL)` を書く。

### 元の配列を変更しない
`tab` はそのまま。新しい配列 `result` に結果を格納する。

### malloc(length + 1) は不要
文字列ではなく int 配列なのでヌル終端は不要。`malloc(sizeof(int) * length)` で十分。
