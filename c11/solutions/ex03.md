# ex03 — ft_count_if

## 要件

| 項目 | 内容 |
|------|------|
| ファイル | `ft_count_if.c` |
| プロトタイプ | `int ft_count_if(char **tab, int length, int (*f)(char *))` |
| 使える関数 | None |
| やること | `f` が0以外を返す要素の数を `length` の範囲で数える |

---

## 考え方

- `i < length` の範囲でループ（NULL 終端ではなく `length` で制御）
- `f(tab[i]) != 0` なら `count++`
- 最後に `count` を返す

---

## 解答コード

```c
int     ft_count_if(char **tab, int length, int (*f)(char *))
{
    int i;
    int count;

    i = 0;
    count = 0;
    while (i < length)
    {
        if (f(tab[i]))
            count++;
        i++;
    }
    return (count);
}
```

---

## ハマりポイント

### `tab[i] != 0 && i < length` はNG
`length` で範囲を制御するのが仕様。NULL チェックを追加すると `length` より前に NULL がある配列で正しく動かない。

### ft_any との違い
| | ft_any | ft_count_if |
|---|---|---|
| 終端 | NULL ポインタ | length |
| 戻り値 | 1 or 0 | 条件を満たす個数 |
