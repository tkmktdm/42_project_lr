## 考え方

- **階乗の定義**：n! = n × (n-1) × ... × 2 × 1
- 0! = 1、1! = 1（数学的定義）
- 負の数は無効 → 0 を返す
- 反復（while ループ）で実装する点が ex01（再帰）との違い

### 計算の流れ

```
5! の計算（反復）:

  nb=5, i=5
  
  i=5: nb = 5 × 4 = 20,  i=4
  i=4: nb = 20 × 3 = 60, i=3
  i=3: nb = 60 × 2 = 120, i=2
  i=2: nb = 120 × 1 = 120, i=1
  i=1: ループ終了
  
  return 120
```

### 用語メモ

- **反復（iterative）**：ループで繰り返す。スタックを消費しない
- **再帰（recursive）**：関数が自分自身を呼び出す。スタックを消費する
- **スタックオーバーフロー**：再帰が深くなりすぎるとスタックが溢れてクラッシュ

## 解答コード

```c
int	ft_iterative_factorial(int nb)
{
    int	i;

    i = nb;
    if (nb < 0 || nb > 12)
        return (0);
    else if (nb == 0 || nb == 1)
        return (1);
    while (i > 1)
    {
        nb = nb * (i - 1);
        i--;
    }
    return (nb);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `i = nb` | nb を乗数カウンタとして別変数に退避（nb を積算に使うため） |
| `nb < 0 \|\| nb > 12` | 負の数は無効、13! は int オーバーフロー（仕様外）→ 0 を返す |
| `nb == 0 \|\| nb == 1` | 0! = 1, 1! = 1 の特例を先に処理 |
| `nb = nb * (i - 1)` | 現在の積に次の乗数をかける |

## ハマりポイント

### ❌ NG: i と nb を混同する

```c
while (nb > 1)
{
    nb = nb * (nb - 1);  // nb が変化してしまい乗数がおかしくなる
    nb--;
}
```

→ 積算用と乗数カウンタ用に変数を分ける

---

### ❌ NG: 0 の扱いを忘れる

```c
if (nb < 0)
    return (0);
// nb == 0 の特例を書かないと while (i > 1) は実行されず return (nb) = return (0) になる
// → 0! = 0 になってしまう（正しくは 1）
```

→ `nb == 0 || nb == 1` を先に `return (1)` で処理する
