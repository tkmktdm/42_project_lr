# ex03 — ft_recursive_power

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_recursive_power.c` |
| プロトタイプ | `int  ft_recursive_power(int nb, int power);` |
| 使える関数 | なし（None） |
| 禁止 | グローバル変数、外部関数すべて |
| やること | nb の power 乗を再帰で返す。power < 0 なら 0。0^0 = 1 |

---

## 考え方

- ex02（反復）と同じ計算を再帰で表現する
- **再帰の定義**：nb^power = nb × nb^(power-1)
- ベースケース：
  - power < 0 → 0
  - power == 0 → 1
  - power == 1 → nb（これで止めると乗数 1 回分の無駄な再帰を省ける）

### 再帰の展開

```
ft_recursive_power(5, 3) の展開:

  ft_recursive_power(5, 3)
    → 5 × ft_recursive_power(5, 2)
         → 5 × ft_recursive_power(5, 1)
                   → return 5  ← ベースケース
         ← 5 × 5 = 25
    ← 5 × 25 = 125
```

---

## メモリ図解

```
ft_recursive_power(5, 3) のスタック

  ┌──────────────────────────────────┐ ← (5, 3): 待機
  │ nb=5, power=3                    │
  ├──────────────────────────────────┤ ← (5, 2): 待機
  │ nb=5, power=2                    │
  ├──────────────────────────────────┤ ← (5, 1): return 5
  │ nb=5, power=1  → return 5        │
  └──────────────────────────────────┘

  戻りながら積算:
    5 → 5×5=25 → 5×25=125
```

## 解答コード

```c
int	ft_recursive_power(int nb, int power)
{
    if (power < 0)
        return (0);
    if (power == 0)
        return (1);
    if (power > 1)
        return (nb * ft_recursive_power(nb, power - 1));
    return (nb);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `if (power < 0) return (0)` | 仕様：負のべき乗は 0 |
| `if (power == 0) return (1)` | 0^0 を含む全ての x^0 = 1 |
| `if (power > 1) return (nb * ...)` | 再帰ステップ |
| `return (nb)` | power == 1 のとき nb^1 = nb |

## ハマりポイント

### ❌ NG: ベースケースの順番を間違える

```c
if (power == 0)      // OK
    return (1);
if (power < 0)       // power < 0 のチェックが後になる → -1 のとき 1 が返ってしまう
    return (0);
```

→ `power < 0` を先にチェックする
