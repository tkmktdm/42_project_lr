# ex05 — ft_sqrt

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_sqrt.c` |
| プロトタイプ | `int  ft_sqrt(int nb);` |
| 使える関数 | なし（None） |
| 禁止 | グローバル変数、外部関数すべて |
| やること | nb の整数平方根があればその値を返す。無理数（整数平方根なし）なら 0 を返す |

---

## 考え方

- **整数平方根**：i × i = nb となる整数 i が存在するか探す
- 存在すれば i を返す、なければ 0 を返す
- `sqrt()` は使えない → 1 から順に `i * i == nb` を確認するループ
- `i * i` が int オーバーフローしないよう上限を設ける（46341^2 > INT_MAX）

### なぜ 46341 が上限か

```
INT_MAX = 2147483647

46340^2 = 2147395600  ← INT_MAX 以内
46341^2 = 2147488281  ← INT_MAX (2147483647) を超える → オーバーフロー

∴ i <= 46341 が安全な上限
```

---

## メモリ図解

```
ft_sqrt(25) の探索

  i=0: 0*0=0  ≠ 25 → 次
  i=1: 1*1=1  ≠ 25 → 次
  i=2: 2*2=4  ≠ 25 → 次
  i=3: 3*3=9  ≠ 25 → 次
  i=4: 4*4=16 ≠ 25 → 次
  i=5: 5*5=25 = 25 → return 5 ✓

ft_sqrt(2) の探索

  i=0: 0*0=0 ≠ 2 → 次
  i=1: 1*1=1 ≠ 2, i=2 > 2/2=1 → ループ終了
  → return 0（整数平方根なし）
```

---

## 解答コード

```c
int	ft_sqrt(int nb)
{
    int	i;

    i = 0;
    if (nb < 0)
        return (0);
    if (nb == 1)
        return (1);
    while (i <= nb / 2 && i <= 46341)
    {
        if (i * i == nb)
            return (i);
        i++;
    }
    return (0);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `if (nb < 0) return (0)` | 負の数の平方根は実数で存在しない → 0 |
| `if (nb == 1) return (1)` | 1の特例（ループに入る前に返す） |
| `i <= nb / 2` | √nb ≤ nb/2 なので探索範囲を半分に絞る（高速化） |
| `i <= 46341` | int オーバーフロー防止（46341^2 が INT_MAX 超え） |
| `i * i == nb` | 完全平方数かどうかの判定 |

## ハマりポイント

### ❌ NG: sqrt() を使う

```c
#include <math.h>
return ((int)sqrt(nb));  // math.h は使用不可 + 浮動小数点誤差あり
```

→ 整数で `i * i == nb` をループチェックする

---

### ❌ NG: オーバーフローを考慮しない

```c
while (i * i <= nb)  // i が大きくなると i*i がオーバーフローして負になる
```

→ `i <= 46341` の上限を設けるか、`i <= nb / i` の形で比較する

---

### ❌ NG: nb = 0 の扱い

```c
if (nb == 0)
    return (0);  // 0 の場合は return 0 が正しいが、ループでも同じ結果になる
```

→ `i=0` からスタートして `0*0==0` で return 0 するので特例不要（コードが通る）
