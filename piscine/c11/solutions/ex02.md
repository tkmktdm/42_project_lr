# ex02 — ft_any

## 要件

| 項目 | 内容 |
|------|------|
| ファイル | `ft_any.c` |
| プロトタイプ | `int ft_any(char **tab, int (*f)(char *))` |
| 使える関数 | None |
| やること | 配列の要素のいずれかで `f` が0以外を返したら1、全て0なら0を返す |

---

## 考え方

- `tab` は NULL ポインタ終端（`length` 引数なし）
- 1つでも `f(tab[i]) != 0` なら即 `return (1)`
- 全部回り終わったら `return (0)`

---

## 解答コード

```c
int     ft_any(char **tab, int (*f)(char *))
{
    int i;

    i = 0;
    while (tab[i])
    {
        if (f(tab[i]))
            return (1);
        i++;
    }
    return (0);
}
```

---

## ハマりポイント

### NULL 終端のチェック
`while (tab[i] != 0)` と `while (tab[i])` は同義。後者の方が慣用的。

### length 引数がない
ex03 の `ft_count_if` と違い、`length` がない。NULL で終端を検知する。
