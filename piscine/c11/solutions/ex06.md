# ex06 — ft_sort_string_tab

## 要件

| 項目 | 内容 |
|------|------|
| ファイル | `ft_sort_string_tab.c` |
| プロトタイプ | `void ft_sort_string_tab(char **tab)` |
| 使える関数 | None |
| やること | NULL 終端の文字列配列を ASCII 順にソートする |

---

## 考え方

- バブルソートで実装（隣り合う要素を比較して交換）
- `ft_strcmp` を `static` 関数として同ファイルに定義
- ポインタを交換（文字列の中身は変えない）
- 交換が発生したら先頭に戻る（`i = 0`）

---

## 解答コード

```c
static int  ft_strcmp(char *s1, char *s2)
{
    int i;

    i = 0;
    while (s1[i] && s2[i] && s1[i] == s2[i])
        i++;
    return ((unsigned char)s1[i] - (unsigned char)s2[i]);
}

void    ft_sort_string_tab(char **tab)
{
    int     i;
    int     len;
    char    *tmp;

    len = 0;
    while (tab[len])
        len++;
    i = 0;
    while (i < len - 1)
    {
        if (ft_strcmp(tab[i], tab[i + 1]) > 0)
        {
            tmp = tab[i];
            tab[i] = tab[i + 1];
            tab[i + 1] = tmp;
            i = 0;
        }
        else
            i++;
    }
}
```

---

## ハマりポイント

### unsigned char でキャスト
```c
return ((unsigned char)s1[i] - (unsigned char)s2[i]);
```
`char` はプラットフォームによって符号付き/なしが変わるため `unsigned char` にキャストして比較する。

### ポインタを交換する
```c
tmp = tab[i];        // ポインタをコピー
tab[i] = tab[i+1];  // ポインタを交換
tab[i+1] = tmp;
```
文字列そのものをコピーするのではなく、ポインタだけ交換する。

### ft_strcmp は static
このファイル内でしか使わないので `static` をつける。
