# ex00 — ft_foreach

## 要件

| 項目 | 内容 |
|------|------|
| ファイル | `ft_foreach.c` |
| プロトタイプ | `void ft_foreach(int *tab, int length, void (*f)(int))` |
| 使える関数 | None |
| やること | 配列の全要素に関数 `f` を順番に適用する |

---

## 考え方

- `tab[0]` から `tab[length-1]` まで順にループ
- 各要素を `f(tab[i])` で呼び出すだけ
- 戻り値なし（`void`）なので返すものは何もない

---

## 解答コード

```c
void    ft_foreach(int *tab, int length, void (*f)(int))
{
    int i;

    i = 0;
    while (i < length)
    {
        f(tab[i]);
        i++;
    }
}
```

---

## ハマりポイント

### 関数ポインタの書き方
```c
void (*f)(int)   // 「int を受け取り void を返す関数」へのポインタ
```
呼び出しは `f(tab[i])` または `(*f)(tab[i])` どちらでもOK。

### ポインタ演算版（別解）
```c
int *end = tab + length;
while (tab < end)
    f(*tab++);
```
どちらも正解。Norminette的にはインデックス版の方が読みやすい。
