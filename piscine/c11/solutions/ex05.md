# ex05 — do-op

## 要件

| 項目 | 内容 |
|------|------|
| ディレクトリ | `ex05/` |
| 提出ファイル | プログラムに必要な全ファイル |
| 使える関数 | `write` |
| やること | `./do-op 値1 演算子 値2` で計算結果を出力するプログラム |

演算子: `+` `-` `*` `/` `%`

---

## ファイル構成

```
ex05/
├── main.c         ← ft_putnbr, 演算子チェック, main
├── op.c           ← ft_add, ft_sub, ft_mul, ft_div, ft_rem
├── ft_atoi.c      ← 文字列→int変換
├── ft.h           ← プロトタイプ宣言
└── Makefile
```

## 設計のポイント

### 関数ポインタ配列で演算子を処理
```c
int (*fptr[5])(int, int);
fptr[0] = &ft_add;   // '+'
fptr[1] = &ft_sub;   // '-'
fptr[2] = &ft_mul;   // '*'
fptr[3] = &ft_div;   // '/'
fptr[4] = &ft_rem;   // '%'
```
演算子文字列 `"+-*/%"` の何番目かを `idx` として、`fptr[idx](a, b)` で呼び出す。

### 演算子は必ず1文字
```c
if (op[0] == '\0' || op[1] != '\0')
    // 無効 → "0\n" を出力
```
`"++"` や `"plus"` などは無効扱い → `0` を出力。

### ft_putnbr は static
`main.c` 内でのみ使う → `static void ft_putnbr(int nbr)`

### op関数は計算して返すだけ
出力は `main` が担当。`ft_div`/`ft_rem` だけゼロ除算エラーを `write` で出力して `return (0)`。

---

## 各ケースの挙動

| 入力 | 出力 | 理由 |
|------|------|------|
| `./do-op` | （なし） | argc != 4 |
| `./do-op 1 + 1` | `2` | 通常の加算 |
| `./do-op 1 p 1` | `0` | 無効演算子 |
| `./do-op 42amis - --+-20toto12` | `62` | ft_atoi が数字部分を解析 |
| `./do-op toto3 + 4` | `4` | ft_atoi("toto3") = 0 |
| `./do-op 25 / 0` | `Stop : division by zero` | ゼロ除算 |
| `./do-op 25 % 0` | `Stop : modulo by zero` | ゼロ剰余 |

---

## ハマりポイント

### ft_putnbr の再帰
```c
// 桁を上から出力するために再帰
if (n >= 10)
    ft_putnbr(n / 10);  // 上の桁を先に出力
c = n % 10 + '0';
write(1, &c, 1);
```

### write の第2引数はアドレス
```c
write(1, c, 1);   // ❌ コンパイルエラー
write(1, &c, 1);  // ✅
```

### ゼロ除算後に ft_putnbr を呼ばない
```c
result = fptr[idx](ft_atoi(av[1]), ft_atoi(av[3]));
if ((idx == 3 || idx == 4) && ft_atoi(av[3]) == 0)
    return (0);  // ← Stop メッセージはすでに出力済み、ft_putnbr を呼ばずに終了
ft_putnbr(result);
write(1, "\n", 1);
```
