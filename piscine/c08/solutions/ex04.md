# ex04 — ft_strs_to_tab

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_strs_to_tab.c` + `ft_stock_str.h` |
| 提出先 | `ex04/` |
| プロトタイプ | `struct s_stock_str *ft_strs_to_tab(int ac, char **av);` |
| 使える関数 | `malloc`, `free` |
| やること | 文字列配列を `t_stock_str` 構造体配列に変換して返す |

### 構造体の仕様 (ft_stock_str.h)

```c
typedef struct s_stock_str
{
    int     size;   // 文字列の長さ
    char    *str;   // 元の文字列へのポインタ
    char    *copy;  // 文字列のコピー (malloc で確保)
}           t_stock_str;
```

### 関数の仕様

- `av` の順序を保持する
- 配列は malloc で動的確保
- **最後の要素の `str` は `0` にする**（配列の終端マーカー）
- エラー時は `NULL` を返す

---

## 考え方

1. `ac + 1` 個分の `struct s_stock_str` を malloc で確保（終端用に +1）
2. `av[i]` ごとに:
   - `tab[i].size` = `ft_strlen(av[i])`
   - `tab[i].str`  = `av[i]`（ポインタのコピー、新たにmallocしない）
   - `tab[i].copy` = `ft_strdup(av[i])`（malloc でコピーを確保）
3. `tab[ac].str = 0` で終端
4. malloc 失敗 → NULL を返す

### 用語メモ

- **動的配列**: `malloc(sizeof(struct s_stock_str) * (ac + 1))` で実行時にサイズを決めて確保
- **ft_strdup**: `malloc` してから文字列をコピーする自作関数（標準の `strdup` は使用不可）
- **終端マーカー**: `NULL` 終端の文字列と同様の考え方。`tab[ac].str = 0` で「ここで終わり」を示す

## 解答コード

```c
#include "ft_stock_str.h"
#include <stdlib.h>

int     ft_strlen(char *str)
{
    int i;

    i = 0;
    while (str[i] != '\0')
        i++;
    return (i);
}

char    *ft_strdup(char *src)
{
    char    *p;
    int     len;
    int     i;

    i = 0;
    len = ft_strlen(src);
    p = malloc(sizeof(char) * (len + 1));
    if (p == NULL)
        return (NULL);
    while (src[i] != '\0')
    {
        p[i] = src[i];
        i++;
    }
    p[len] = '\0';
    return (p);
}

static int  ft_fill_tab(struct s_stock_str *tab, int ac, char **av)
{
    int i;

    i = 0;
    while (i < ac)
    {
        tab[i].size = ft_strlen(av[i]);
        tab[i].str = av[i];
        tab[i].copy = ft_strdup(av[i]);
        if (!tab[i].copy)
            return (0);
        i++;
    }
    tab[ac].str = 0;
    return (1);
}

struct s_stock_str  *ft_strs_to_tab(int ac, char **av)
{
    struct s_stock_str  *tab;

    tab = malloc(sizeof(struct s_stock_str) * (ac + 1));
    if (!tab)
        return (NULL);
    if (!ft_fill_tab(tab, ac, av))
        return (NULL);
    return (tab);
}
```

**なぜそう書くか**

| コード | 理由 |
|--------|------|
| `ac + 1` 個確保 | 終端マーカー `tab[ac].str = 0` の分が必要 |
| `tab[i].str = av[i]` | av は外部の配列なのでコピーしなくてよい（ポインタをそのまま保持） |
| `tab[i].copy = ft_strdup(av[i])` | copy はコピー。`malloc` で新たにメモリを確保する |
| `static` な `ft_fill_tab` | 外部から呼ばれない補助関数は `static` でスコープを限定 |

## ハマりポイント

### ❌ NG: 終端マーカーを忘れる

```c
// tab[ac].str = 0; を書き忘れると ft_show_tab がループを終了できない
```

→ `ft_show_tab` は `par->str != NULL` でループするので、終端がないと無限ループまたは不正アクセス

---

### ❌ NG: malloc 失敗チェックなし

```c
tab = malloc(...);
// NULLチェックなしで tab[0].size = ... → セグフォ
```

→ `malloc` は失敗したら NULL を返す。必ずチェックして NULL を返す

---

### ❌ NG: copy に malloc せず str のアドレスを代入

```c
tab[i].copy = av[i];  // str と copy が同じアドレスを指す
```

→ `copy` は「コピー」なので独立したメモリが必要。`ft_strdup` で別途確保する
