# ex03 — ft_atoi

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_atoi.c` |
| プロトタイプ | `int  ft_atoi(char *str);` |
| 使える関数 | None |
| 禁止 | グローバル変数 |
| やること | 文字列の先頭を整数に変換する |

**PDF の実行例**
```
$> ./a.out " ---+--+1234ab567"
-1234
```

**変換ルール（PDF より）**

1. 先頭の空白文字（`isspace` 定義: ` \t\n\r\f\v`）を読み飛ばす
2. `+` / `-` が任意の数続く場合がある。`-` の数が**奇数**なら負、**偶数**なら正
3. 連続する数字を 10 進数として読む
4. 数字以外の文字が現れたらそこで終了
5. オーバーフロー・アンダーフローは**処理しない**（未定義動作でよい）

---

## 考え方

- 3 フェーズで処理する: ①空白スキップ → ②符号カウント → ③数字変換
- 符号は「`-` の個数が奇数なら `sign = -1`、偶数なら `sign = 1`」
- 数字変換は `result = result * 10 + (str[i] - '0')`
- `str[i] - '0'` で文字 `'5'` → 数値 `5` に変換できる

### 用語メモ

- **`isspace`**: スペース、タブ、改行など空白系文字を判定。`' '` `'\t'` `'\n'` `'\r'` `'\f'` `'\v'`
- **`'0'` = 48**: 文字 `'0'` の ASCII 値。`str[i] - '0'` で数字文字を整数値に変換

---

## メモリ図解

```
str = " ---+--+1234ab567"

フェーズ①: 空白スキップ
  " " → i=0 は isspace → i++
  i=1 から "-" → 空白終了

フェーズ②: 符号カウント
  i=1 '-' sign=-1  count=1（奇数）
  i=2 '-' sign=1   count=2（偶数）
  i=3 '-' sign=-1  count=3（奇数）
  i=4 '+' → '+' はカウントしない（符号方向は変えない）
  i=5 '-' sign=1   count=4（偶数）
  i=6 '-' sign=-1  count=5（奇数）
  i=7 '+' → スキップ
  i=8 '1' → 数字 → フェーズ③へ

フェーズ③: 数字変換
  result = 0
  '1' → result = 0*10 + 1 = 1
  '2' → result = 1*10 + 2 = 12
  '3' → result = 12*10 + 3 = 123
  '4' → result = 123*10 + 4 = 1234
  'a' → 数字以外 → 終了

result * sign = 1234 * -1 = -1234  ✓
```

## 解答コード

```c
int     ft_atoi(char *str)
{
    int i;
    int sign;
    int result;

    i = 0;
    sign = 1;
    result = 0;
    while (str[i] == ' ' || (str[i] >= '\t' && str[i] <= '\r'))
        i++;
    while (str[i] == '+' || str[i] == '-')
    {
        if (str[i] == '-')
            sign = -sign;
        i++;
    }
    while (str[i] >= '0' && str[i] <= '9')
    {
        result = result * 10 + (str[i] - '0');
        i++;
    }
    return (result * sign);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `str[i] == ' ' \|\| (str[i] >= '\t' && str[i] <= '\r')` | isspace の 6 文字を手動チェック（関数禁止のため） |
| `sign = -sign` | `-` を見るたびに符号を反転。偶数個なら +1、奇数個なら -1 になる |
| `str[i] >= '0' && str[i] <= '9'` | 数字文字の範囲判定（isdigit の代わり） |
| `result * 10 + (str[i] - '0')` | 桁を上げながら数値を積み上げる |

## ハマりポイント

### ❌ NG: isspace / isdigit / atoi などを使う

```c
#include <ctype.h>
while (isspace(str[i]))  /* 使用可能関数が None → 不正 */
```

→ `nm -u` で外部シンボルが検出される

---

### ❌ NG: `+` で sign を反転する

```c
if (str[i] == '-')
    sign = -sign;
else if (str[i] == '+')
    sign = -sign;  /* '+' も反転するのは間違い */
```

→ PDF では `-` の数の奇偶で符号が決まる。`+` は何も変えない

---

### ❌ NG: main 関数を提出する

```c
int main(void)  /* main は提出ファイルに含めない */
{
    printf("%d", ft_atoi("42"));
    ...
}
```

→ テスト側の main と二重定義になりコンパイルエラー。提出前にコメントアウトまたは削除する
