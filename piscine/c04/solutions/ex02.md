# ex02 — ft_putnbr

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_putnbr.c` |
| プロトタイプ | `void  ft_putnbr(int nb);` |
| 使える関数 | `write` のみ |
| 禁止 | グローバル変数 |
| やること | int 型に収まるすべての数値を標準出力に出力する |

---

## 考え方

- 数値を文字として出力するには「桁を 1 文字ずつ取り出す」必要がある
- `nb % 10` で 1 の位、`nb / 10` で残りの桁を得る → 再帰が自然
- 負数は先に `-` を出力してから絶対値を処理
- **INT_MIN の罠**: `int` の `-2147483648` を `-n` すると `int` の範囲を超えオーバーフロー → `long` に変換してから処理する

### 用語メモ

- **`'0'` = 48**: 数字 `0` の ASCII コード。`(n % 10) + '0'` で数字文字に変換できる
- **INT_MIN**: `-2147483648`。INT_MAX は `2147483647`。`-INT_MIN` はオーバーフローするので `long` が必要

---

## メモリ図解

```
ft_putnbr(123) の再帰の流れ

  呼び出し①: nb=123 → n=123 → n>9 なので再帰
    呼び出し②: nb=12  → n=12  → n>9 なので再帰
      呼び出し③: nb=1   → n=1   → n≤9 なのでここで初めて出力
        n = (1 % 10) + '0' = '1'  → write '1'
      ③ return
    n = (12 % 10) + '0' = '2'  → write '2'
    ② return
  n = (123 % 10) + '0' = '3'  → write '3'
  ① return

出力順: 1 → 2 → 3 = "123" ✓

ft_putnbr(-2147483648) の場合:
  long n = -2147483648L   ← int に収まる
  n < 0 → write('-')
  n = -n = 2147483648L    ← long なのでオーバーフローしない
  → 再帰で "2147483648" を出力
  結果: "-2147483648" ✓
```

## 解答コード

```c
#include <unistd.h>

void    ft_putnbr(int nb)
{
    long    n;

    n = nb;
    if (n < 0)
    {
        write(1, "-", 1);
        n = -n;
    }
    if (n > 9)
        ft_putnbr(n / 10);
    n = (n % 10) + '0';
    write(1, &n, 1);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `long n = nb;` | INT_MIN の `-n` オーバーフローを防ぐため long で受ける |
| `write(1, "-", 1)` | 負数の符号を先に出す |
| `ft_putnbr(n / 10)` | 上位桁から先に出すために再帰（最後に return されるので上位が先） |
| `n = (n % 10) + '0'` | 1 の位を ASCII 文字に変換して n に格納 |
| `write(1, &n, 1)` | long n の 先頭 1 バイト = 最下位バイト = 文字コード（リトルエンディアン） |

## ハマりポイント

### ❌ NG: int のまま -INT_MIN を計算する

```c
int n = nb;
if (n < 0)
    n = -n;  /* n = -(-2147483648) → オーバーフロー、UB */
```

→ INT_MIN を int で反転すると未定義動作。`long` に変換してから反転する

---

### ❌ NG: 未使用変数を宣言する

```c
void ft_putnbr(int nb)
{
    long    n;
    int     i;   /* 使わない → -Wall -Werror でコンパイルエラー */
    ...
```

→ `-Wunused-variable` が `-Wall` に含まれるため、`-Werror` と組み合わせるとエラーになる

---

### ❌ NG: printf を使う

```c
printf("%d", nb);  /* write のみ許可 */
```
