# ex05 — ft_atoi_base

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_atoi_base.c` |
| プロトタイプ | `int  ft_atoi_base(char *str, char *base);` |
| 使える関数 | None |
| 禁止 | グローバル変数 |
| やること | `str` をベース `base` の数値として整数に変換する |

**ft_atoi との違い**
- 数字の読み取りが 10 進数ではなく指定ベース
- 無効なベースの場合は `0` を返す

**無効なベースの条件（0 を返す）**
- ベースが空 or 長さ 1 以下
- ベースに `+` または `-` が含まれる
- ベースに空白文字（スペース・タブ・改行等）が含まれる ← **ex04 との違い**
- ベースに重複文字が含まれる

**動作ルール（ft_atoi と共通）**
1. 先頭の空白文字（isspace: ` \t\n\r\f\v`）をスキップ
2. `+`/`-` が任意の数続く。`-` の数が奇数なら負
3. ベースの文字が続く限り数値を積み上げる
4. ベース外の文字が出たら終了

---

## 考え方

- 数字を読む際、`str[i]` がベースの何番目の文字かを検索する（`char_index`）
- `char_index` が -1 なら「ベース外の文字 = 終了」
- 変換式: `result = result * base_length + char_index(str[i], base)`
- 符号処理・空白スキップは ft_atoi と同じ

### 用語メモ

- **基数変換（逆方向）**: ft_putnbr_base は整数→文字列、ft_atoi_base は文字列→整数
- **`char_index`**: ベース文字列を線形探索して一致する位置を返す

## メモリ図解

```
ft_atoi_base("FF", "0123456789ABCDEF")
  base_length = 16

  str[0] = 'F' → char_index('F', base) = 15
  str[1] = 'F' → char_index('F', base) = 15

  n = 0
  n = 0  * 16 + 15 = 15
  n = 15 * 16 + 15 = 255

  return 255  ✓

ft_atoi_base(" -42", "0123456789")
  base_length = 10

  skip_prefix: ' ' スキップ → '-' → mflg=1 → '4' で終了
  str = "42"

  n = 0 * 10 + 4 = 4
  n = 4 * 10 + 2 = 42

  mflg=1（奇数）→ n = -42
  return -42  ✓

ft_atoi_base("ff", "0123456789ABCDEF")
  str[0] = 'f' → char_index('f', "0123456789ABCDEF") = -1（小文字なので一致なし）
  即終了 → return 0  ✓（大文字と小文字は別物）
```

## 解答コード

```c
int     has_dup(char *base)
{
    int i;
    int j;

    i = 0;
    while (base[i])
    {
        j = i + 1;
        while (base[j])
        {
            if (base[i] == base[j])
                return (1);
            j++;
        }
        i++;
    }
    return (0);
}

int     base_check(char *base)
{
    int i;

    i = 0;
    while (base[i])
    {
        if (base[i] == '+' || base[i] == '-')
            return (0);
        if (base[i] == ' ' || (base[i] >= 9 && base[i] <= 13))
            return (0);
        i++;
    }
    if (i <= 1)
        return (0);
    if (has_dup(base))
        return (0);
    return (i);
}

int     char_index(char c, char *base)
{
    int i;

    i = 0;
    while (base[i])
    {
        if (base[i] == c)
            return (i);
        i++;
    }
    return (-1);
}

char    *skip_prefix(char *str, int *mflg)
{
    while ((*str >= 9 && *str <= 13) || *str == ' ')
        str++;
    while (*str == '+' || *str == '-')
    {
        if (*str == '-')
            (*mflg)++;
        str++;
    }
    return (str);
}

int     ft_atoi_base(char *str, char *base)
{
    int     nx;
    int     mflg;
    long    n;

    nx = base_check(base);
    if (!nx)
        return (0);
    mflg = 0;
    str = skip_prefix(str, &mflg);
    n = 0;
    while (char_index(*str, base) != -1)
    {
        n = n * nx + char_index(*str, base);
        str++;
    }
    if (mflg % 2 == 1)
        n = -n;
    return ((int)n);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `base[i] >= 9 && base[i] <= 13` | ASCII 9〜13 は `\t\n\v\f\r`。スペース（32）と合わせて isspace の 6 文字を手動チェック |
| `char_index(*str, base) != -1` | -1 はベース外文字を意味する。ループ継続条件として使う |
| `n = n * nx + char_index(...)` | 基数変換の核心。桁を上げながらインデックスを足す |
| `(int)n` | `long` で計算した結果を最終的に `int` にキャスト（オーバーフロー対策の long から戻す） |

## ハマりポイント

### ❌ NG: base_check でスペースチェックを忘れる

```c
/* ex04 の base_check をそのままコピーするとスペース条件が抜ける */
while (base[i])
{
    if (base[i] == '+' || base[i] == '-')
        return (0);
    /* ← スペースチェックが必要 */
    i++;
}
```

→ ex05 は ex04 と異なりスペース・タブ・改行なども無効条件

---

### ❌ NG: char_index を 2 回呼ぶのが非効率（パフォーマンス問題ではないがコードが冗長）

```c
while (char_index(*str, base) != -1)
{
    n = n * nx + char_index(*str, base);  /* 2 回目の呼び出し */
```

→ 1 回呼んで変数に入れるか、提出コードのように 2 回呼んでも動作は正しい

---

### ❌ NG: `"0123456789ABCDEF"` で `"ff"` を処理するとき 0 にならない実装

```c
/* 小文字と大文字を同一視してはいけない */
```

→ ベースが大文字のみなら小文字はベース外文字として扱い、読み取り即終了 → 0 を返す
