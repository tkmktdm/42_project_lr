# ex02 — ft_split

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_split.c` |
| プロトタイプ | `char **ft_split(char *str, char *charset);` |
| 使える関数 | `malloc` |
| やること | charset の各文字を区切りとして文字列を分割し、配列で返す |
| 禁止 | 入力文字列を変更しない。空文字列を配列に含めない |
| 末尾 | 配列の最後の要素は `NULL` |

---

## 考え方

- `charset` の**各文字**が区切り文字になる（文字列全体ではなく1文字ずつ）
- 区切り文字が連続しても空文字列は配列に入れない
- 3ステップに分解すると実装しやすい
  1. 単語数を数える（`count_words`）
  2. 配列を `malloc` する
  3. 各単語をコピーして配列に格納（`get_word`）

### 用語メモ

- **charset**: 区切り文字の集合。`".,!"` なら `.` も `,` も `!` も区切り文字
- **`malloc`**: ヒープにメモリを確保する。`free` で解放が必要

---

## メモリ図解

```
ft_split("hello,,world", ",") の処理

  str: h e l l o , , w o r l d \0
                   ↑区切り ↑区切り

  count_words → 2

  malloc(sizeof(char *) * 3)  ← count + 1（NULL 用）
  ┌──────────┬──────────┬──────┐
  │ words[0] │ words[1] │ NULL │
  └────┬─────┴────┬─────┴──────┘
       │           │
       ▼           ▼
  "hello\0"   "world\0"   ← get_word で個別に malloc
```

## 解答コード

```c
#include <stdlib.h>

int	is_sep(char c, char *charset)
{
    while (*charset)
    {
        if (*charset == c)
            return (1);
        charset++;
    }
    return (0);
}

int	count_words(char *str, char *charset)
{
    int	count;
    int	in_word;

    count = 0;
    in_word = 0;
    while (*str)
    {
        if (is_sep(*str, charset))
            in_word = 0;
        else if (in_word == 0)
        {
            in_word = 1;
            count++;
        }
        str++;
    }
    return (count);
}

char	*get_word(char *str, char *charset)
{
    char	*copy;
    char	*temp;
    int		len;

    len = 0;
    while (str[len] && !is_sep(str[len], charset))
        len++;
    copy = malloc(len + 1);
    if (!copy)
        return (NULL);
    temp = copy;
    while (len-- > 0)
        *temp++ = *str++;
    *temp = '\0';
    return (copy);
}

char	**ft_split(char *str, char *charset)
{
    char	**words;
    int		count;
    int		i;

    i = 0;
    count = count_words(str, charset);
    words = malloc(sizeof(char *) * (count + 1));
    if (!words)
        return (NULL);
    while (*str)
    {
        while (*str && is_sep(*str, charset))
            str++;
        if (!*str)
            break ;
        words[i] = get_word(str, charset);
        if (!words[i])
            return (NULL);
        while (*str && !is_sep(*str, charset))
            str++;
        i++;
    }
    words[count] = NULL;
    return (words);
}
```

**なぜそう書くか**

| コード | 理由 |
|--------|------|
| `in_word` フラグ | 連続する区切り文字をスキップして単語の開始だけカウントする |
| `count + 1` で malloc | 末尾 NULL 用の 1 要素分が必要 |
| `get_word` で len を先に計算 | 正確なサイズで malloc できる |
| `words[count] = NULL` | 配列の終端マーカー |

## ハマりポイント

### ❌ NG: charset を1つの区切り文字列として扱う

```c
// "ab" を区切りにしようとして 'a' と 'b' 両方を区切り文字にしていない
if (str[i] == *charset)  // 先頭文字しか見ていない
```

→ `is_sep` で charset の全文字をループして確認する

---

### ❌ NG: 空文字列を配列に入れる

```c
// 区切り文字が連続していても word をコピーしてしまう
```

→ `count_words` の `in_word` フラグで連続する区切りをまとめて1区切りとして扱う

---

### ❌ NG: 末尾 NULL を忘れる

```c
words = malloc(sizeof(char *) * count);  // NULL 用が足りない
```

→ `count + 1` で確保し `words[count] = NULL` を設定する

---

### ❌ NG: 入力文字列を変更する

```c
str[i] = '\0';  // 区切り文字を書き換えてはいけない
```

→ `str` は読むだけ。コピーは `get_word` 内で新しく `malloc` する
