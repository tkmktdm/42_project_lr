## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_find_next_prime.c` |
| プロトタイプ | `int  ft_find_next_prime(int nb);` |
| 使える関数 | なし（None） |
| 禁止 | グローバル変数、外部関数すべて |
| やること | nb が素数ならそのまま返す。素数でなければ nb より大きい次の素数を返す |

---

## 考え方

- 「nb が素数かチェック → 素数なら return → 違えば nb++ して繰り返す」
- 素数判定は `ft_is_prime` を内部で実装（ex06 と同じロジック）
- **nb が素数ならそのまま返す**（nb+1 の次の素数ではなく、nb 自身）

### 動作例

```
ft_find_next_prime(12):
  is_prime(12) = 0 → nb=13
  is_prime(13) = 1 → return 13

ft_find_next_prime(2):
  is_prime(2) = 1 → return 2（そのまま）

ft_find_next_prime(-5):
  is_prime(-5) = 0 → nb=-4 → ... → nb=2
  is_prime(2) = 1 → return 2
```

---

## メモリ図解

```
ft_find_next_prime(15) の処理フロー

  nb=15 → ft_is_prime(15): 15%3=0 → 0（素数でない）
  nb=16 → ft_is_prime(16): 16%2=0 → 0
  nb=17 → ft_is_prime(17): 2〜4 で割り切れない → 1（素数）
  → return 17
```

## 解答コード

```c
int	ft_is_prime(int nb)
{
    int	i;

    i = 2;
    if (nb < 2)
        return (0);
    if (nb == 2)
        return (1);
    while (i * i <= nb)
    {
        if (nb % i == 0)
            return (0);
        i++;
    }
    return (1);
}

int	ft_find_next_prime(int nb)
{
    while (nb < 2147483647)
    {
        if (ft_is_prime(nb) == 1)
            return (nb);
        nb++;
    }
    return (0);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `while (nb < 2147483647)` | INT_MAX を超えないよう上限を設定 |
| `if (ft_is_prime(nb) == 1)` | 現在の nb が素数かチェック |
| `nb++` | 素数でなければ次の数へ |
| `return (0)` | INT_MAX 付近で素数が見つからなかった場合（実際はほぼ起きない） |

## ハマりポイント

### ❌ NG: 「次の素数」を「nb の次から探す」と誤解する

```c
nb++;  // 先に nb を進めてしまう
while (...)
    if (ft_is_prime(nb)) return nb;
```

→ `ft_find_next_prime(2)` が 3 を返してしまう（正しくは 2）
→ 必ず nb 自身から素数判定を始める
