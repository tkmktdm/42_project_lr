---

## 考え方

- **素数の定義**：2以上の整数で、1と自分自身以外で割り切れない数
- 2 〜 √nb の範囲で割り切れる数が1つでもあれば素数でない
- √nb まで調べれば十分な理由：約数はペアで存在するため、小さい方は必ず √nb 以下

### なぜ `i * i <= nb` で止めていいのか

```
nb = 36 の約数ペア:
  2 × 18
  3 × 12
  4 ×  9
  6 ×  6  ← √36 = 6（ここが折り返し点）

→ i が √nb を超えたら、もう新しい約数は見つからない
```

### 用語メモ

- **素数**：1と自分自身以外で割り切れない 2 以上の整数
- **合成数**：素数でない 2 以上の整数（例：4, 6, 9, 15）
- **`%`（剰余演算子）**：`a % b` → a を b で割った余り。0 なら割り切れる

---

## メモリ図解

```
ft_is_prime(15) の流れ

  nb = 15,  i = 2 からスタート

  i=2: i*i=4  <= 15 → 15 % 2 = 1 ≠ 0 → 次へ
  i=3: i*i=9  <= 15 → 15 % 3 = 0     → 割り切れた！ → return 0

ft_is_prime(11) の流れ

  nb = 11,  i = 2 からスタート

  i=2: i*i=4  <= 11 → 11 % 2 = 1 ≠ 0 → 次へ
  i=3: i*i=9  <= 11 → 11 % 3 = 2 ≠ 0 → 次へ
  i=4: i*i=16 > 11  → ループ終了
  → 割り切れなかった → return 1（素数）
```

---

## 解答コード

```c
int	ft_is_prime(int nb)
{
	int	i;

	i = 2;
	if (nb < 2)
		return (0);
	if (nb == 2)
		return (1);
	while (i * i <= nb)
	{
		if (nb % i == 0)
			return (0);
		i++;
	}
	return (1);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `if (nb < 2)` | 0, 1, 負の数をまとめて除外（0と1は素数ではない） |
| `if (nb == 2)` | 2 は唯一の偶数の素数。while で弾かれないよう先に処理 |
| `while (i * i <= nb)` | √nb まで調べれば十分。`i <= nb/i` と同義だが乗算の方が安全 |
| `if (nb % i == 0)` | 割り切れた = 約数がある = 素数でない |
| `return (1)` | ループを抜けた = 約数がなかった = 素数 |

