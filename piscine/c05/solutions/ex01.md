# ex01 — ft_recursive_factorial

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_recursive_factorial.c` |
| プロトタイプ | `int  ft_recursive_factorial(int nb);` |
| 使える関数 | なし（None） |
| 禁止 | グローバル変数、外部関数すべて |
| やること | nb の階乗を再帰で計算して返す。無効な引数は 0 を返す |

---

## 考え方

- **再帰の定義**：n! = n × (n-1)! → 問題を「1つ小さい問題」に分解して自分を呼ぶ
- ベースケース（再帰を止める条件）が必須
  - nb < 0 → 0（無効）
  - nb == 0 または nb == 1 → 1
- ex00（反復）との違いは「ループを使わず自分自身を呼ぶ」点だけ

### 再帰の展開

```
ft_recursive_factorial(5) の呼び出しスタック:

  ft_recursive_factorial(5)
    → 5 × ft_recursive_factorial(4)
         → 4 × ft_recursive_factorial(3)
              → 3 × ft_recursive_factorial(2)
                   → 2 × ft_recursive_factorial(1)
                              → return 1  ← ベースケース
                   ← 2 × 1 = 2
              ← 3 × 2 = 6
         ← 4 × 6 = 24
    ← 5 × 24 = 120
```

### 用語メモ

- **ベースケース**：再帰の終了条件。これがないと無限ループ → スタックオーバーフロー
- **再帰呼び出し**：関数が自分自身を呼ぶこと

```
    1 → 2×1=2 → 3×2=6 → 4×6=24
```

## 解答コード

```c
int	ft_recursive_factorial(int nb)
{
    if (nb < 0)
        return (0);
    if (nb == 1 || nb == 0)
        return (1);
    return (nb * ft_recursive_factorial(nb - 1));
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `if (nb < 0) return (0)` | 負の数は無効。最初にガード |
| `if (nb == 1 \|\| nb == 0) return (1)` | ベースケース。これがないと無限再帰 |
| `nb * ft_recursive_factorial(nb - 1)` | 問題を 1 つ小さくして自己呼び出し |
