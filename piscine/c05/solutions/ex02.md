# ex02 — ft_iterative_power

## 要件メモ

| 項目 | 内容 |
|------|------|
| ファイル名 | `ft_iterative_power.c` |
| プロトタイプ | `int  ft_iterative_power(int nb, int power);` |
| 使える関数 | なし（None） |
| 禁止 | グローバル変数、外部関数すべて |
| やること | nb の power 乗を反復で返す。power < 0 なら 0。0^0 = 1 |

---

## 考え方

- **べき乗の定義**：nb^power = nb × nb × ... × nb（power 回）
- power == 0 → 1（何の数の0乗も1）
- power < 0 → 0（仕様）
- 反復（while ループ）で実装

### 計算の流れ

```
5^3 の計算:

  nb=5, base=5, power=3

  power=3 > 1: nb = 5 × 5 = 25, power=2
  power=2 > 1: nb = 25 × 5 = 125, power=1
  power=1: ループ終了

  return 125
```

### 用語メモ

- **底（base）**：べき乗される数（nb）
- **指数（exponent / power）**：何回かけるかを示す数

---

## メモリ図解

```
ft_iterative_power(5, 3) の変数の変化

  スタックフレーム（1枚）
  ┌──────────────────────────────┐
  │ nb   │ base │ power │ 説明   │
  ├──────┼──────┼───────┼────────┤
  │   5  │   5  │   3   │ 初期値 │
  │  25  │   5  │   2   │ 5×5   │
  │ 125  │   5  │   1   │ 25×5  │
  └──────┴──────┴───────┴────────┘
  return 125

  base を別変数で保持する理由:
    nb を直接かけ続けると基底を忘れてしまうため
```

---

## 解答コード

```c
int	ft_iterative_power(int nb, int power)
{
    int	base;

    base = nb;
    if (power < 0)
        return (0);
    if (power == 0)
        return (1);
    while (power > 1)
    {
        nb = nb * base;
        power--;
    }
    return (nb);
}
```

**行ごとメモ**

| コード | なぜそう書くか |
|--------|---------------|
| `base = nb` | nb が変化するので元の値を保存 |
| `if (power < 0) return (0)` | 仕様：負のべき乗は 0 |
| `if (power == 0) return (1)` | 0^0 を含む全ての x^0 = 1 |
| `nb = nb * base` | nb に base をかけ続ける |

---

## ハマりポイント

### ❌ NG: base を別変数で持たない

```c
while (power > 1)
{
    nb = nb * nb;  // nb が変化するので正しいべき乗にならない
    power--;
}
```

→ `base` に元の `nb` を保存して、常に `base` をかける

---

### ❌ NG: power == 0 を忘れる（0^0 の罠）

```c
if (power < 0)
    return (0);
// power == 0 を処理しないと while (0 > 1) でループに入らず
// return (nb) = return (0) になる → 0^0 = 0（誤り、正しくは 1）
```
