4. convert_hundreds() — グループ1つを英語に変換

group="347", len=3, unit_idx=1 の場合

① len==3 かつ group[0]('3') != '0' → print_hundreds("347")
dict_lookup("3") → "three"    dict_lookup("100") → "hundred"
出力: three hundred·
② len>=2 → convert_tens(&group[len-2]) = convert_tens("47")
group[0]='4' != '1' → list="40" → dict_lookup("40") → "forty"
group[1]='7' != '0' → convert_ones("7") → "seven"
出力: forty·seven
③ print_unit(dict, 1)
unit_key = "1000" → dict_lookup("1000") → "thousand"
出力: ·thousand
グループ全体の出力: three hundred forty seven thousand

convert_tens の分岐

group[0] == '1'（10〜19）
→ convert_ones(group)
"15" → dict["15"] → "fifteen"
"11" → dict["11"] → "eleven"
group[0] != '0' かつ != '1'（20〜99）
→ dict[X0] + convert_ones(group[1])
"37" → dict["30"]="thirty" + "seven"
"50" → dict["50"]="fifty"（ones=0スキップ）
group[0] == '0'（1〜9）
→ convert_ones(&group[1])
"07" → dict["7"] → "seven"
"00" → 0 → 何も出力しない
